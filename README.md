# bit a bit

Una web de microaprendizaje de desarrollo de software con cápsulas breves, preguntas de repaso, favoritos y seguimiento del progreso. El avance se guarda en el navegador mediante `localStorage`.

## Ejecutar

Abre `Microaprendizaje/index.html` en el navegador o inicia un servidor local:

```bash
cd Microaprendizaje
python3 -m http.server 8000
```

Visita `http://localhost:8000`. No requiere instalación ni backend.
